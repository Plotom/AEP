# AEP - 2º Semestre

Esse repositório é sobre uma atividade bimestral do segundo semestre do
curso de **ADS (Análise e Desenvolvimento de Sistemas)**.

O projeto tem como tema o **Programa Saúde na Escola (PSE)** e tem como
objetivo analisar uma problemática relacionada à saúde no ambiente
escolar e planejar uma solução computacional para auxiliar nesse contexto.
